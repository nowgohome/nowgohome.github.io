Privacy Policy

Animal Shorts · Last updated: October 26, 2026

Animal Shorts ("the app") is a private tool used only by the owner of the Animal Shorts YouTube channel to upload daily videos to that channel.

Data the app accesses

With the channel owner's permission, the app uses the YouTube Data API (YouTube API Services) to upload videos, set their titles and descriptions, and add caption tracks on the owner's channel. It does not read, collect, or store personal data about viewers or any other YouTube users.

How data is used and stored

The only credential the app keeps is the channel owner's own authorization token. It is stored as an encrypted secret in the owner's private GitHub repository and is used solely to upload the owner's videos. No data is sold, shared with third parties, or used for advertising.

YouTube and Google

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account permissions page. Revoking access stops the app from uploading; no further data is kept.
